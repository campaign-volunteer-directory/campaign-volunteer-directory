About this directory

A searchable directory of progressive 2026 candidates who are looking for volunteers, compiled from the public Campaign Volunteer Directory spreadsheet — a crowdsourced list maintained by volunteers. The data is re-synced automatically from that spreadsheet every 12 hours.

The source data is preserved exactly as entered

Every sync stores the spreadsheet's raw content byte-for-byte as downloaded — nothing is edited, cleaned, or rewritten. You can download the exact file below and verify it with its SHA-256 checksum. The searchable version on this site is derived from it, never the other way round.

Issue chips are the candidates' own words

The issue categories you can filter by are extracted deterministically from the stance texts themselves — no invented labels, no editorializing. If the spreadsheet ever carries an "Issues:" column, its values are used verbatim. Everything is recomputed automatically on every sync.

Independent and open

This site is an independent project — not affiliated with, sponsored by, or endorsed by Lime Accordion or any candidate. The entire pipeline (sync, validation, site) is open source and reviewable in the GitHub repository.

Not an endorsement

A listing here is not an endorsement of any candidate or their positions. The directory is simply a collection of campaigns that need help. Please research candidates before getting involved.

Search tips
  • housing healthcare — candidates matching all words
  • -ward — exclude a word (e.g. war -ward)
  • medic* — matches word prefixes (medicare, Medicaid…)
  • "medicare for all" — match an exact phrase
  • VA — state abbreviations work too (Virginia)
  • Issue chips — click to include, shift-click to exclude
